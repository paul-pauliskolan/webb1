Kap 5.2 - Hämta och ändra element

DOM gör att JavaScript kan hitta HTML-element och ändra dem.

Mål

  • Hämta element med document.querySelector.
  • Ändra text med textContent.
  • Ändra klasser med classList.
  • Reagera på klick med addEventListener.

Hitta ett element

querySelector använder CSS-selektorer. Det betyder att du kan leta efter exempelvis en klass, ett id eller ett elementnamn.

const button = document.querySelector(".theme-button");
const message = document.querySelector("#message");

Det här elementet har id message.

JavaScript kan hitta båda elementen med selektorerna i koden.

Ändra text

textContent ändrar texten inuti ett element.

message.textContent = "Knappen klickades";

Den här texten ändras när du klickar.

Lyssna på events

addEventListener kopplar en funktion till något som händer, till exempel ett klick.

button.addEventListener("click", function () {
    message.textContent = "Du klickade på knappen";
});

Väntar på klick...

Växla klass

classList.toggle lägger till klassen om den saknas och tar bort den om den redan finns.

document.body.classList.toggle("dark-mode");

Klassen är av.

Den här rutan får klassen is-active.

Övningar

Förbered arbetet

  1. Skapa en mapp som heter kap 5-2 i din mapp Webbutveckling 1.
  2. Öppna bara mappen kap 5-2 i Visual Studio Code via Arkiv → Öppna mapp.
  3. Skapa ovn5-2.html. Gör båda övningarna i denna fil. Skapa också undermappen js med filen main.js för din JavaScript-kod.
  4. Skriv CSS i ett <style>-element inuti <head>. Om du utökar arbetet till fler än en HTML-sida ska du skapa en extern CSS-fil, till exempel style.css, och länka den från varje sida.
  5. Koppla JavaScript-filen i head med <script src="js/main.js" defer></script>. Spara filerna och öppna ovn5-2.html i webbläsaren. Testa efter varje ändring.

Övning 1: Låt knappar ändra ett meddelande

Skapa en informationsruta för en skolklubb där besökaren kan välja vilken information som visas.

  1. Skriv en fullständig HTML-struktur och skapa en sektion med en rubrik, ett stycke med id="club-message" och två knappar med type="button". Ge knapparna olika id och texterna ”Visa mötestid” och ”Visa mötesplats”.
  2. Hämta stycket och de två knapparna med document.querySelector. Spara referenserna i varsin const.
  3. Lägg till en egen klicklyssnare med addEventListener på varje knapp.
  4. Låt den ena knappen ändra styckets textContent till en mötestid och den andra till en mötesplats. Texten ska ändras först när besökaren trycker på knappen.
  5. Ge rutan tydliga avstånd och läsbara färger med CSS. Skriv en JavaScript-kommentar som förklarar skillnaden mellan att hitta ett element och att ändra dess text.

Kontrollera och förklara: Tryck på knapparna växelvis flera gånger. Rätt meddelande ska visas utan omladdning och konsolen ska vara fri från fel. Testa även knapparna med Tab och Enter.

Övning 2: Växla utseende med en CSS-klass

Fortsätt i samma HTML-fil och skapa ett aktivitetskort som besökaren kan markera.

  1. Lägg till ett kort med rubrik, beskrivning och en knapp med texten ”Växla markering”. Ge kortet och knappen egna id så att de inte blandas ihop med den första övningens element.
  2. Skriv grundstilen för kortet och en CSS-klass .is-highlighted som ändrar både bakgrund och kantlinje. Lägg även en synlig etikett i kortet som bara visas när klassen finns, så att markeringen inte enbart uttrycks med färg.
  3. Hämta kortet och knappen med querySelector. Lyssna på knappens klick.
  4. Använd classList.toggle("is-highlighted") för att växla klassen på kortet. Låt CSS sköta utseendet.
  5. Kontrollera i utvecklarverktygens Elements att klassen läggs till och tas bort när du trycker på knappen.

Kontrollera och förklara: Första trycket ska markera kortet och nästa ska återställa det. Testa minst fyra tryck och kontrollera att knapparna från övning 1 fortfarande fungerar. Förklara varför klassnamnet saknar punkt i classList.toggle.
