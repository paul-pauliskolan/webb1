Kap 5.3 - Formulär och feedback

JavaScript kan läsa formulärfält och ge användaren direkt feedback.

Mål

  • Lyssna på ett formulärs submit-event.
  • Stoppa vanlig skickning med preventDefault().
  • Läsa värdet från ett fält med value.
  • Visa feedback i sidan.

Submit-event

Lyssna på formuläret, inte bara på knappen. Då fungerar koden även om användaren trycker Enter i ett fält.

const form = document.querySelector("#contact-form");
const nameInput = document.querySelector("#name");
const feedback = document.querySelector("#feedback");

form.addEventListener("submit", function (event) {
    event.preventDefault();
    feedback.textContent = "Hej " + nameInput.value + "!";
});

Skriv ditt namn och tryck Enter eller klicka på knappen.

Läsa fältvärden

value innehåller det användaren har skrivit eller valt i ett formulärfält.

const email = document.querySelector("#email");

if (email.value === "") {
    feedback.textContent = "Skriv en e-postadress.";
}

Skriv en e-postadress och testa.

Feedback ska vara tydlig

Feedback ska berätta vad som hände och vad användaren behöver göra. Skriv hellre konkret än bara "fel".

feedback.textContent = "Meddelandet måste vara minst 10 tecken.";

Feedback visas här.

Övningar

Förbered arbetet

  1. Skapa en mapp som heter kap 5-3 i din mapp Webbutveckling 1.
  2. Öppna bara mappen kap 5-3 i Visual Studio Code via Arkiv → Öppna mapp.
  3. Skapa ovn5-3.html. Gör båda övningarna i denna fil. Skapa också undermappen js med filen main.js för din JavaScript-kod.
  4. Skriv CSS i ett <style>-element inuti <head>. Om du utökar arbetet till fler än en HTML-sida ska du skapa en extern CSS-fil, till exempel style.css, och länka den från varje sida.
  5. Koppla JavaScript-filen i head med <script src="js/main.js" defer></script>. Spara filerna och öppna ovn5-3.html i webbläsaren. Testa efter varje ändring.

Övning 1: Hälsa på besökaren med ett formulär

Skapa ett formulär som visar en personlig hälsning direkt i sidan.

  1. Skriv en fullständig HTML-struktur. Skapa ett form-element med ett namnfält, en label kopplad med for och id samt en knapp med type="submit".
  2. Lägg ett tomt stycke för feedback efter knappen och ge det ett eget id och aria-live="polite", så att uppdateringen kan meddelas av hjälpmedel.
  3. Hämta formuläret, namnfältet och feedbackstycket med querySelector. Lyssna på formulärets submit-event och använd event.preventDefault().
  4. Läs namnet med value. Använd if för att visa ”Skriv ditt namn först.” när värdet är en tom sträng. Annars ska feedbacken innehålla namnet, till exempel ”Hej Sam! Välkommen till klubben.”
  5. Visa feedback med textContent. Gör kontrollerna i JavaScript i denna övning så att även ett tomt fält når din submit-lyssnare.

Kontrollera och förklara: Testa tomt fält, ett ifyllt namn och ett nytt namn. Prova både submit-knappen och Enter i namnfältet. Sidan ska stanna kvar utan omladdning och feedbacken ska ersättas vid varje försök.

Övning 2: Visa en sammanfattning av ett val

Fortsätt i samma HTML-fil med ett separat formulär för en prova-på-aktivitet. Det ska bara visa en sammanfattning i sidan.

  1. Skapa ett nytt formulär med ett e-postfält av typen email, en select med två aktiviteter och en submit-knapp med texten ”Visa mitt val”. Ge alla fält tydliga etiketter och unika id.
  2. Ge e-postfältet required så att webbläsaren kontrollerar att en e-postadress är ifylld. Använd en påhittad adress när du testar, till exempel elev@example.com.
  3. Skapa ett eget feedbackstycke med aria-live="polite". Koppla en submit-lyssnare till det nya formuläret och stoppa vanlig skickning med preventDefault().
  4. Läs e-postfältets och listans value. Använd begripliga värden för aktiviteterna, till exempel ”Webbdesign” och ”Spelkväll”.
  5. Visa en sammanfattning med vald aktivitet och adress via textContent. Skriv också att detta är en övning: ingen anmälan sparas och inget mejl skickas.

Kontrollera och förklara: Prova tom adress, en felaktig adress och elev@example.com. Webbläsaren ska stoppa de två första fallen. Byt aktivitet och skicka igen; sammanfattningen ska uppdateras utan omladdning. Kontrollera att formulären fungerar oberoende av varandra.
