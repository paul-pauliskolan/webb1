Kap 3.1 - Vad CSS gör

CSS styr presentationen: färg, storlek, avstånd, layout och andra visuella egenskaper.

Mål

  • Förstå vad CSS används till.
  • Kunna koppla en extern CSS-fil till HTML.
  • Förstå grunderna i selektor, deklaration, egenskap och värde.
  • Känna till att CSS styrs av kaskad, arv och prioritet.

HTML utan CSS

Om du skriver HTML utan CSS visar webbläsaren sidan med sina standardregler. De kallas ofta user-agent stylesheet. Därför blir en h1 stor och fet, medan ett p-element får marginaler före och efter.

CSS låter dig skriva dina egna regler ovanpå webbläsarens standard.

CSS-regelns delar

h1 {
    color: green;
    font-size: 2rem;
}
Så visas regeln i webbläsaren

Rubrik

  • h1 är selektorn. Den väljer vilka element som påverkas.
  • color och font-size är egenskaper.
  • green och 2rem är värden.
  • En egenskap och ett värde bildar en deklaration.

Vanliga CSS-enheter

Tal i CSS behöver ofta en enhet. Vilken enhet som passar beror på vad du vill styra.

  • px är en CSS-pixel och passar till exempel för tunna kantlinjer.
  • rem utgår från sidans grundläggande textstorlek och passar ofta för text och avstånd.
  • % beskriver en andel, ofta i förhållande till elementets behållare.
  • ch motsvarar ungefär bredden på tecknet 0 i den aktuella fonten och kan användas för att begränsa textraders längd.

Vissa egenskaper kan använda enhetslösa värden. line-height: 1.5 betyder till exempel att radavståndet blir 1,5 gånger textstorleken.

Tre sätt att lägga till CSS

Extern CSS-fil

Det vanligaste och bästa arbetssättet i kursen är att lägga CSS i en egen fil.

<link rel="stylesheet" href="styles.css">

CSS i head

Vid små tester kan CSS ligga i ett style-element i head.

<style>
    h1 { color: green; }
</style>

Inline-CSS

Inline-CSS skrivs direkt i ett HTML-element. Det bör undvikas i vanliga projekt eftersom kod och utseende blandas.

<h1 style="color: green">Rubrik</h1>

Kaskad och arv

CSS läses med regler för vilken deklaration som vinner. En regel som kommer senare kan vinna över en tidigare regel om de har samma styrka. Vissa egenskaper, till exempel textfärg och font, kan ärvas från föräldraelement till barn.

Övningar

Så arbetar du: Gör först kunskapsfrågorna utan att titta i kapitlet. Skriv på papper eller i ett dokument och markera det du är osäker på. Jämför sedan med svarsstödet och kapitlet, rätta dina svar och förklara det du missade med egna ord. I kodövningen ska du förutsäga resultatet innan du testar.

Övning 1: Förklara CSS innan du testar

  1. Förklara skillnaden mellan HTML och CSS. Varför får en rubrik ett utseende även om du inte har skrivit någon egen CSS?
  2. I regeln h1 { color: green; font-size: 2rem; }: peka ut selektorn, de två egenskaperna, deras värden och en hel deklaration.
  3. Beskriv de tre sätten att lägga till CSS. Vilket sätt gör det enkelt att låta flera HTML-sidor dela samma utseende?
  4. Vad betyder arv? Ge ett exempel på en egenskap som kan ärvas. Förklara också vad px, rem, procent och ch kan användas till enligt kapitlet.
Svarsstöd – öppna efter ditt eget försök
  1. HTML ger struktur och innehåll; CSS styr utseendet. Webbläsarens standardregler ger element ett utseende även utan egen CSS.
  2. h1 är selektorn. color och font-size är egenskaper; green och 2rem är värden. color: green är en hel deklaration.
  3. CSS kan ligga i en extern fil, i style i head eller inline. En extern fil kan delas av flera HTML-sidor.
  4. Textfärg och font kan ärvas från föräldrar. px passar exempelvis till tunna kanter; rem till text och avstånd; procent anger en andel; ch kan begränsa radlängd.

Förbered kodövningen

  1. Skapa mappen kap 3-1 i din mapp Webbutveckling 1.
  2. Öppna bara mappen kap 3-1 i Visual Studio Code via Arkiv → Öppna mapp.
  3. Skapa ovn3-1.html. Skriv CSS i ett <style>-element inuti <head>. Om du skapar fler än en HTML-sida ska du använda en extern CSS-fil som du länkar från varje sida.

Övning 2: Förutsäg, testa och felsök en CSS-regel

  1. Skapa en fullständig HTML-sida med svenska som språk, sidtitel och viewport-inställning. Skriv en huvudrubrik och två stycken om ett eget intresse. Använd inga bilder i denna övning.
  2. Skriv först h1 { color: green; } i style-elementet. Lägg sedan h1 { color: blue; } under den första regeln. Skriv vilken färg du tror rubriken får och varför innan du öppnar sidan.
  3. Öppna sidan och jämför med din förutsägelse. Byt ordning på reglerna och testa igen. Förklara varför resultatet ändras när reglerna har samma selektor och egenskap.
  4. Flytta sedan CSS-koden till en extern fil som heter style.css. Ta bort style-elementet och koppla filen i head med <link rel="stylesheet" href="style.css">. Detta moment tränar kapitlets mål att koppla en extern CSS-fil.
  5. Ändra en färg i CSS-filen och kontrollera att sidan ändras efter omladdning. Ta tillfälligt bort kolon i en color-deklaration, undersök felmarkeringen i VS Code och rätta felet. Skriv två meningar om vad du lärde dig om ordning och filkoppling.
Svarsstöd – öppna efter din förutsägelse och ditt test
  1. Sidan ska ha HTML-grundstruktur, en huvudrubrik och två stycken. Här behövs varken bilder eller senare kapitels layouttekniker.
  2. Rubriken blir blå: den blå regeln kommer sist och har samma selektor och egenskap som den gröna.
  3. När reglerna byter ordning blir rubriken grön. Vid samma styrka vinner den senare deklarationen.
  4. CSS-filen ska innehålla reglerna utan style-taggar. Link-elementets href ska vara style.css och ligga i head. Utseendet ska finnas kvar efter flytten.
  5. En färgändring ska synas efter att du sparat och laddat om. Ett saknat kolon gör deklarationen ogiltig. Kontrollera filnamn och href om hela stilen saknas.

Återblick vid nästa lektion: Välj två frågor du var osäker på och besvara dem igen utan att läsa dina tidigare svar. Förklara också en CSS-regel från kodövningen ur minnet. Kontrollera och rätta efteråt.
