Kap 3.4 - Klasser, id och selektorstrategi

Bra selektorer gör CSS lättare att läsa, återanvända och felsöka.

Mål

  • Använda typselektorer, klassselektorer och id-selektorer.
  • Förstå gruppering, kedjeselektorer och härstammande selektorer.
  • Känna till pseudoklasser, specificitet och arv.

Typselektor

En typselektor väljer alla element av en viss typ.

p {
    line-height: 1.5;
}

Det här stycket påverkas eftersom regeln väljer alla p-element i exemplet.

Även detta stycke får samma radavstånd.

Klassselektor

Klasser kan återanvändas på många element. I CSS skrivs klasser med punkt.

<p class="intro-text">Text</p>

.intro-text {
    font-weight: 700;
}

Det här stycket har klassen intro-text och blir därför fetare.

Det här stycket saknar klassen och påverkas inte av klassregeln.

Använd gärna bindestreck i klassnamn. Undvik mellanslag om du menar ett enda klassnamn.

ID-selektor

Ett id ska vara unikt på sidan. Det kan användas för ankarlänkar, formulärkopplingar och JavaScript. I CSS skrivs id med #.

#contact-form {
    border: 1px solid #5eead4;
}

Välj klass i första hand när stilen ska kunna återanvändas.

Gruppering och DRY

Om flera selektorer ska få samma deklarationer kan du gruppera dem med kommatecken.

h1,
h2,
h3 {
    line-height: 1.15;
}

Det följer DRY-principen: Don't Repeat Yourself.

Kedja och härstamning

.card.highlight {
    border-color: orange;
}

article p {
    max-width: 70ch;
}
Det här elementet har både card och highlight, så kantlinjen blir orange.

Det här stycket ligger inuti article och påverkas av article p.

.card.highlight väljer element som har båda klasserna. article p väljer p-element som ligger någonstans inuti article.

I den andra regeln sätter max-width en övre gräns för bredden. 70ch motsvarar ungefär bredden på 70 nolltecken i den aktuella fonten och hjälper till att hålla textraderna läsbart korta.

Pseudoklasser

Pseudoklasser väljer element i ett visst tillstånd, till exempel länkar när muspekaren är över dem eller när de får tangentbordsfokus.

a:hover {
    text-decoration: underline;
}

a:focus {
    outline: 2px solid #5eead4;
}

Hovra över länken eller tabba till den för att se :hover och :focus.

Specificitet

Om flera regler påverkar samma egenskap avgör specificitet och ordning vilken som vinner. Inline-stil är stark, id är starkare än klass, och klass är starkare än typselektor. Undvik !important om du inte har en mycket tydlig anledning.

!important gör en enskild deklaration starkare än vanliga deklarationer. Exempel: color: red !important;. Det kan verka som en snabb lösning, men gör kaskaden svårare att förstå och tvingar ofta fram ännu fler starka regler senare. Lös i första hand problemet med tydliga selektorer, rätt ordning och rimlig specificitet.

Övningar

Så arbetar du: Gör först kunskapsfrågorna utan att titta i kapitlet. Skriv på papper eller i ett dokument och markera det du är osäker på. Jämför sedan med svarsstödet och kapitlet, rätta dina svar och förklara det du missade med egna ord. I kodövningen ska du förutsäga resultatet innan du testar.

Övning 1: Förutsäg vilka element selektorerna väljer

  1. Förklara skillnaden mellan p, .intro och #intro. Vilken typ passar bäst för en stil som ska användas på flera element, och varför?
  2. Jämför .card.highlight och .card .highlight. Vad betyder punkterna och mellanslaget? Förklara även vad article p väljer.
  3. Vad betyder kommatecknet i h1, h2, h3? Hur skiljer det sig från mellanslaget i article p? Koppla till DRY.
  4. Förklara skillnaden mellan hover och focus. Om typ-, klass- och id-regler försöker ändra samma textfärg, vilken är starkast bland dessa vanliga regler? Vad avgör när reglerna har samma specificitet?
Svarsstöd – öppna efter ditt eget försök
  1. p är typselektor, .intro klassselektor och #intro id-selektor. Klasser kan återanvändas; id ska vara unikt på sidan.
  2. .card.highlight kräver båda klasserna på samma element. .card .highlight väljer ett highlight-element inuti ett card-element. Article p väljer stycken inuti article.
  3. Komma grupperar alternativa selektorer som ska dela deklarationer. Mellanslag anger härstamning. Gruppering minskar upprepning enligt DRY.
  4. Hover gäller muspekaren och focus det fokuserade elementet. Bland dessa vanliga regler är id starkare än klass och klass starkare än typ. Vid lika specificitet vinner den senare.

Förbered kodövningen

  1. Skapa mappen kap 3-4 i din mapp Webbutveckling 1.
  2. Öppna bara mappen kap 3-4 i Visual Studio Code via Arkiv → Öppna mapp.
  3. Skapa ovn3-4.html. Skriv CSS i ett <style>-element inuti <head>. Om du skapar fler än en HTML-sida ska du använda en extern CSS-fil som du länkar från varje sida.

Övning 2: Pröva selektorer och förklara vinnande regler

  1. Skapa en fullständig HTML-sida med ett article-element som har class="card highlight". Lägg två stycken i det och ett tredje stycke utanför. Ge det första stycket både class="intro" och id="lead". Lägg också en länk till https://developer.mozilla.org/ med texten ”MDN Web Docs”.
  2. Skriv p { color: navy; }, .intro { color: green; } och #lead { color: maroon; }. Skriv vilka färger de tre styckena får innan du testar. Byt reglernas ordning och förklara varför id-regeln fortfarande styr det första styckets färg.
  3. Testa .card.highlight { border: 2px solid teal; } och article p { background-color: #eeeeee; }. Förutsäg vilka ytor som påverkas. Ta sedan bort highlight från artikelns class-attribut, testa igen och återställ klassen.
  4. Gruppera h1 och h2 med kommatecken för ett gemensamt line-height. Ge länken olika tydliga stilar med a:hover och a:focus. Testa muspekare, Tab och Enter.
  5. Ta bort id-regeln för textfärg och kontrollera vilken regel som då vinner. Skriv en kort förklaring till resultatet och varför tydliga klasser ofta är enklare att återanvända än starka id-regler. Använd inte inline-stil eller important i testet.
Svarsstöd – öppna efter din förutsägelse och ditt test
  1. Artikeln ska ha båda klasserna. Första stycket ska ha klassen intro och det unika id:t lead. Det tredje stycket ska ligga utanför article.
  2. Första stycket blir maroon och de två andra navy. Id-regeln är starkare än klass- och typreglerna även om ordningen ändras.
  3. Artikeln får kantlinjen och båda artikelstyckena grå bakgrund. Stycket utanför påverkas inte av article p. Kantregeln slutar matcha när highlight tas bort.
  4. Rubrikregeln ska använda kommatecken. Länken ska ge synlig återkoppling både vid muspekare och tangentbordsfokus och öppna den angivna webbplatsen.
  5. Utan id-regeln blir första stycket green genom klassen intro. Klasser kan återanvändas och är mindre starka än id-regler, vilket ofta gör dem enklare att kombinera.

Återblick vid nästa lektion: Välj två frågor du var osäker på och besvara dem igen utan att läsa dina tidigare svar. Förklara också en CSS-regel från kodövningen ur minnet. Kontrollera och rätta efteråt.
