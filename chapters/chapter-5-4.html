Kap 5.4 - Små interaktioner utan ramverk

Du kan bygga mycket med vanlig HTML, CSS och lite JavaScript.

Mål

  • Bygga små interaktioner med knapp, event och klass.
  • Förstå när aria-expanded behöver uppdateras.
  • Använda JavaScript för att visa, dölja eller byta läge.

Visa och dölj meny

En vanlig interaktion är en menyknapp på små skärmar. Knappen växlar en klass på menyn.

const menuButton = document.querySelector(".menu-button");
const menu = document.querySelector(".menu");

menuButton.addEventListener("click", function () {
    menu.classList.toggle("is-open");
});

Vad är ARIA?

ARIA står för Accessible Rich Internet Applications. ARIA-attribut ger hjälpmedel, till exempel skärmläsare, extra information om en interaktiv komponents funktion och aktuella läge.

ARIA skapar inte själva funktionen. JavaScript öppnar och stänger fortfarande menyn, medan ARIA beskriver för hjälpmedel vad knappen styr och om menyn är öppen.

  • aria-controls="aria-demo-menu" kopplar knappen till elementet med id="aria-demo-menu".
  • aria-expanded="false" betyder att det styrda innehållet är stängt.
  • aria-expanded="true" betyder att det styrda innehållet är öppet.

Uppdatera tillgängligt läge

Om en knapp öppnar och stänger något bör aria-expanded alltid spegla det verkliga läget. Annars kan det som hjälpmedlet meddelar motsäga det som syns på skärmen.

const isOpen = menu.classList.toggle("is-open");
menuButton.setAttribute("aria-expanded", String(isOpen));

Tabs och aktiva lägen

Tabs, filterknappar och temaväxling bygger ofta på samma idé: hitta element, lyssna på klick och ändra klass eller text.

button.addEventListener("click", function () {
    panel.classList.add("active");
});
Panelen har fått klassen active.

När räcker enkel JavaScript?

För små komponenter behöver du oftast inget ramverk. Börja enkelt och bygg bara mer avancerat när problemet kräver det.

Övningar

Förbered arbetet

  1. Skapa en mapp som heter kap 5-4 i din mapp Webbutveckling 1.
  2. Öppna bara mappen kap 5-4 i Visual Studio Code via Arkiv → Öppna mapp.
  3. Skapa ovn5-4.html. Gör båda övningarna i denna fil. Skapa också undermappen js med filen main.js för din JavaScript-kod.
  4. Skriv CSS i ett <style>-element inuti <head>. Om du utökar arbetet till fler än en HTML-sida ska du skapa en extern CSS-fil, till exempel style.css, och länka den från varje sida.
  5. Koppla JavaScript-filen i head med <script src="js/main.js" defer></script>. Spara filerna och öppna ovn5-4.html i webbläsaren. Testa efter varje ändring.

Övning 1: Bygg en meny som kan öppnas och stängas

Skapa en sida för en skolklubb med en menyknapp och tre länkar till avsnitt på samma sida.

  1. Skriv en fullständig HTML-struktur. Lägg till tre innehållsavsnitt med unika id och en nav med länkar till dem.
  2. Ge navigationen ett id, till exempel club-menu. Skapa en riktig knapp med type="button", aria-controls="club-menu", aria-expanded="false" och texten ”Visa meny”.
  3. Dölj menyn i grundstilen med display: none. Skriv en regel för .is-open som visar den, till exempel med flexbox och gap. Låt menyn börja stängd i alla skärmbredder i denna övning.
  4. Hämta knappen och menyn. Vid klick ska classList.toggle växla is-open på menyn. Spara returvärdet i const isOpen.
  5. Uppdatera knappens aria-expanded med setAttribute("aria-expanded", String(isOpen)). Använd if och else för att låta knapptexten växla mellan ”Dölj meny” och ”Visa meny”.

Kontrollera och förklara: Öppna och stäng menyn flera gånger med mus och med Tab följt av Enter eller mellanslag. Stängda menylänkar ska inte nås med Tab. Kontrollera i Elements att aria-expanded alltid motsvarar det synliga läget och att länkarna leder rätt.

Övning 2: Skapa en utfällbar informationsruta

Fortsätt i samma HTML-fil med en fristående knapp som visar eller döljer praktisk information om klubben.

  1. Skapa en knapp med texten ”Visa praktisk information” och en panel med mötestider, plats och vad besökaren behöver ta med. Ge knappen och panelen egna id.
  2. Koppla knappen till panelen med aria-controls och sätt aria-expanded="false". Dölj panelen med CSS från början och skapa en klass .active som visar den.
  3. Skriv en separat klicklyssnare som växlar panelens active-klass. Uppdatera aria-expanded från returvärdet från classList.toggle.
  4. Låt knapptexten ange om nästa tryck visar eller döljer informationen. Ge panelen läsbara färger, padding och en tydlig kantlinje.
  5. Skriv en JavaScript-kommentar som beskriver det gemensamma mönstret i menyknappen och informationsknappen: hitta element, lyssna på klick och uppdatera innehåll eller läge.

Kontrollera och förklara: Testa att menyn och informationsrutan kan vara öppna samtidigt och kan stängas var för sig. Båda knapparna ska fungera med tangentbord och ha rätt aria-expanded. Ladda om sidan och kontrollera att båda börjar stängda.
