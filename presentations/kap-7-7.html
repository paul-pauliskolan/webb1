DevTools

Öppna Inspektera i Chrome

  1. Öppna sidan.
  2. Högerklicka.
  3. Välj Inspektera.

På Mac kan du även trycka ⌘ + ⌥ + I.

Välj verktyg efter problemet

ElementsConsoleNetwork
  • Elements: undersök HTML och CSS.
  • Console: läs fel och varningar.
  • Network: kontrollera filer och laddning.

Console

Första platsen när JavaScript inte fungerar

Console visar felmeddelanden och varningar från sidan.

Läs särskilt filnamn, radnummer och texten i det röda felet.

Öppna Console

Arbetsgång

  1. Öppna Inspektera.
  2. Välj fliken Console.
  3. Ladda om sidan.
  4. Leta efter röda meddelanden.
  5. Läs filnamn och radnummer.

Cache

Testa med nyhämtade filer

  1. Öppna Network.
  2. Markera Disable cache.
  3. Låt Inspektera vara öppet.
  4. Ladda om sidan.

Då hämtas CSS och JavaScript på nytt under testet.

Snabb testchecklista

Före publicering

  • Smal, mellanbred och bred vy fungerar.
  • Console saknar röda fel.
  • Network saknar 404.
  • Mediafiler har rimlig storlek.
  • Alla länkar fungerar.
  • Tangentbord och fokus fungerar.

Sammanfattning

En enkel testordning

  1. Ändra viewportens bredd.
  2. Läs Console.
  3. Kontrollera Network.
  4. Testa utan cache.
  5. Klicka, tabba och skicka formulär.
  6. Rätta en sak i taget och testa igen.
